# Dikevin/homebrew-tap

Homebrew tap for my tools.

```bash
brew install dikevin/tap/fanear
```

| Cask | What |
|---|---|
| [fanear](https://github.com/Dikevin/fanear-cli) | Read-only CLI and agent skill for FanEar (饭耳) daily records |

Casks here are generated by GoReleaser when a tool is released; edit the tool's `.goreleaser.yaml`, not the files in `Casks/`.
